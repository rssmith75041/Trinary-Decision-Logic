Here’s the distilled reality:

### Why most scenarios “don’t do much”
- **Scenario 1**  
  BranchMaybe forks → both futures immediately hit Merge → states identical → collapse.  
  No register changes.

- **Scenario 2**  
  Simple addition truth table.  
  Only meaningful because it demonstrates Maybe propagation.

- **Scenario 3**  
  True path does a NOP, False path does nothing → both hit Merge → identical → collapse.  
  R1 stays all True.

- **Scenario 4**  
  One of the few that *does* something: True sets R5=True, False sets R5=False → divergence → R5 becomes Maybe.

- **Scenario 5**  
  True and False paths do different work but end identical → collapse → no register changes.

- **Scenario 6**  
  Loop on both sides → both futures converge → collapse → no register changes.

- **Scenario 7**  
  Both futures jump to the same Merge PC → identical → collapse → no register changes.

### The only scenarios with meaningful state mutation
- **Scenario 2** (arithmetic truth table)
- **Scenario 4** (R5 becomes Maybe)

Everything else is essentially a **control‑flow test**:

- Does BranchMaybe fork correctly?  
- Do futures run independently?  
- Do they converge?  
- Does Merge collapse identical states?  
- Does ContextFlag propagate Maybe?  
- Does the VM choose the correct unified PC?
